# 0.04 运行验证与真人试玩

## 证据的含义

本报告严格分开四种结果：自动启动与运行、带断言的脚本验证、实际渲染截图可观察的形态，以及仍需用户判断的体验。自动脚本会瞄准、按键或在固定场景注入 DamageEvent，不能当成真人自然游玩统计，也不能证明“爽”。

## 自动运行 / 脚本验证

- **0.03 回归**：移动、双钩、破坏、Sweep、VFX、场景生命周期、358 栋完整覆盖、墨迹；目标辅助、M03 动力、撞击恢复、八站路线；保留长期物理循环。
- **D01 Core**：首次受损前不展开墙板；只破坏局部；洞口射线为空、旁侧碰撞保留；削角凸体三个轴都有厚度。50% / 60% / 70% 肉核比例边缘路线记录在 `collider_race.json`；削角后最终三个比例均通过，默认保留更宽容的 60%。
- **真实 RAM 路线**：脚本设置瞄准并按起跳 / 前进，调用正常射钩；不赋初速、不直接对塔注入损伤。撞入后松钩，进入空腔，击穿另一面，离开时约 37.5 m/s，再射向出口结构成功。
- **真实 SLASH**：正常射钩与角色运动使绷紧触手扫过样本塔；记录 `last_detach_type = SLASH`，支撑断裂产生宏块。该测试不是直接调用塔的断裂方法。
- **Scar Follow**：改变墙板变换后，伤痕局部变换不变、全局变换跟随；倒塌后的废墟仍携带黑痕。
- **Support Disconnect**：切断 B-C，A+B 仍与地基连接，C+D 是一个失联组件。
- **Macro Cleanup / Secondary**：固定中段切断夹具生成一个宏块，实际接触后塔产生 COLLAPSE，落稳成为静态废墟；没有持续活跃大块。此夹具注入起始 SLASH，后续碰撞和伤害由运行管线产生。
- **Budget / Depth**：4、6、8 个宏块预算分别溢出一个，旧大块转静态；450 次新伤痕申请被约束到 384。Depth 2 接受，Depth 3 不改变几何。
- **场景清理**：包含倒塌期间多次 F5/F6 等效重开，检查回到旧塔林后没有残留新塔 / 管理器，玩家碰撞球恢复旧值。退出修复及原生进程返回码单独验证，不能只凭 PASS 文本忽略进程退出码；分析见 `SHUTDOWN_AUDIT.md`。

最终日志与性能数据位于 `evidence/`，重现命令：`tools/run_checks.ps1 -Rnd -Consequence -Stress`。Windows 导出包另使用 `-- --smoke-test` 验证资源打包、旧路线、真实贯穿和连锁残骸。

## AI 可观察画面

2026-09-14 完整 19 脚本回归通过，实际图形运行退出 0、错误日志为空。三组 12 秒图形采样平均约 59.7 FPS，p95 17.6–19.4 ms；最终最大帧 69 ms，较早一轮 122 ms 的激活尖峰也保留。详细数字与测量边界见 [VALIDATION](../VALIDATION.md)。

无 HUD 的同机同角度截图比较 RAM / SLASH：

- RAM 留下能看见内部梁和另一面墙的洞口，外围残壁仍在，黑痕以撞击中心向外延伸。
- SLASH 保留大部分立面，留下狭长黑线、窄缝与两侧偏移；没有使用整层消失表现切割。
- 结构先延迟起动，随后大块倾斜落下；后塔接触区产生新的缺口和裂纹。全景中接触伤口容易被遮挡，另用接触侧近景确认；这是当前可读性限制。
- 最终倾斜残骸保留为静态碰撞与抓取面，场景不是回到原始几何。

## 每个核心实验的体验观察

| 观察问题 | D01 / RAM | D02 / 伤痕与切口 | D03–D05 / 倒塌与后果 |
|---|---|---|---|
| 伤口是否明显 | 洞、内部与黑色边缘可见 | 黑线与放射纹形态不同 | 后塔接触区可见新伤口 |
| 是否像 Delete | 仍有墙板粒度，但没有整层消失 | 切唇和残壁保留 | 上层实际移动并保留为残骸 |
| 建筑是否有重量 | 飞散方向可见；感受需真人 | 碎屑较少、错位较轻 | 延迟、转动、加速与落稳可见；重量感需真人 |
| 反应太快 / 太慢 | 碰撞立即开洞 | 弱面断裂后有延迟 | 0.22 秒起倾、0.72 秒进入下坠；节奏需真人 |
| 延迟坍塌是否漂亮 | 不适用 | 切口先于宏块起动 | 能观察到分阶段动作，美感需真人 |

| 是否改变下一路线 | 两侧洞口形成穿塔路径 | 削弱后可能移走上层 | 几何与抓取面改变；玩家主动利用需真人 |

## 真人试玩建议

1. **A / Breach Run**：按说明起跳抓正面，入洞后松钩。观察是顺畅穿出，还是被边缘 / 锚点拉回；F8 保存失败位置附近的运行数据。
2. **B / Sever & Fall**：抓前方高梁并向下摆荡。观察切口是否在结构起动之前可读、等待是否拖慢操作。
3. **C / Domino**：切断后先绕到侧面看后塔，再试着直接抓倒下的残壁离开。判断二次碰撞是否值得注意、是否产生有用路线。
4. **D / Dirty Tower**：多次 RAM / SLASH，R 回出发点但不要 F5，观察同一局能否读到自己的破坏历史。

D06 没有开放。本轮优先让真人反馈洞口宽容度、切口辨识度、倒塌节奏和残骸是否值得利用，而不是增加攻击按钮。
