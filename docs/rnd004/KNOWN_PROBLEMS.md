# 0.04 已知问题与当前限制

- 高级后果只在独立实验区域的三座新塔上成立；原 358 栋仍用旧纵向段破坏。实验场与原塔林通过 F4 / F6 切换，未把新系统铺满全城。
- 宏块用作者选定倾倒方向和四个粗壳体代理。它不做精确旋转扫掠；接触恢复时可能与残壁短暂相交。预算溢出或 9 秒时限会就地转静态，任意高空压力夹具会出现冻结在空中的残骸。
- 斜切由水平或垂直预制切唇近似，墨线按 Sweep 方向生成；不是任意角度连续网格切割。
- 静态废墟仍保留多块静态墙板碰撞与绘制对象。384 新伤痕达到上限后删除最老标记；R 保留本局破坏，F5 / 切换实验 / 重开程序不保存世界废墟到磁盘。
- 撞穿需要起跳、足够速度并适时松钩；一直拉着入口锚点可能被拉回。出口附近已经较低，宜及时抓住出口梁。
- 实验台、内部梁、旧建筑使用较便宜的旧破坏结果；实验区 WorldFoundation 作为稳定地基不可破坏。
- 0.03 已记录的全塔林同时分段性能限制仍存在；本版小规模实验的帧率不代表全城高级破坏性能。
- 首次破坏 / 集中展开墙板和伤痕仍可能短暂卡顿：最终图形测量最大帧约 69 ms，较早一次曾达到 122 ms。平均约 59.7 FPS 不能掩盖这个尖峰。
- 二次碰撞伤口可能被落块或塔身遮住；绕到接触侧可看见。高速运动中能否及时注意到后果仍需真人试玩。
- 中文 UI 随包使用 Noto Sans SC，增加约 17.8 MB 未压缩字体资源；避免依赖玩家电脑安装的中文字体。
