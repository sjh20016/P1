# RAVAGE 0.04 · CONSEQUENCE

## 重要变化

- 新增三座重点实验塔：一座可贯穿塔、两座有支撑图的结构塔。原 358 栋塔林及 0.03 路线保留，未整体改写移动系统。
- RAM、SLASH、PULL、COLLAPSE 共用 DamageEvent。PIERCE、SPIN 只保留类型，运行管线拒绝它们。
- 外壳首次受损才展开 384 个作者定义墙板；RAM 打开局部洞口并削掉邻近残壁角部，SLASH 保留两侧错位切唇与狭长断口。
- 伤痕为建筑局部坐标中的黑色 Mesh，随所属墙板、移动大块、静态废墟移动。上限 384，超限淘汰最老伤痕；同一局持续保留。
- 四个 Chunk、三条 Bond 的支撑图以 BFS 检查地基连通性。失联组件作为单个大块，经历抖动、倾斜、加速下坠、实际碰撞、静态残骸。
- 坍塌碰撞产生 COLLAPSE 二次伤害，最多深度 2；每块对同一建筑最多 3 次、间隔至少 0.3 秒。二次碰撞不重复触发全局慢动作。
- 大块预算默认 6，与原 48 个活跃碎片刚体分开。静止大块退出运动更新并恢复残骸碰撞；预算溢出也保留为静态废墟。
- 实验场玩家碰撞球半径 0.35424 m，与肉核和视觉触须分离；返回旧塔林恢复 0.72 m。M03 抓钩算法、辅助瞄准和坠落恢复基线保留。
- 默认中文菜单进入后果实验场；F9 切换四个短实验，F5 重置当前实验，F4 自由塔林，F10 保留的 0.03 路线。
- F3 增加墙板、结构塔、伤痕、大块、残骸、二次伤害与深度计数；F8 保存本局后果实验遥测。
- 内嵌 Noto Sans SC 中文字体并校正字重；移除玩家 / 抓钩之间的脚本类型循环，解决本机 Godot 4.7.2 测试退出阶段的原生崩溃，完整回归正常退出。

1. 首轮无 HUD 截图中，洞口过于方正、外壳融入背景。加入角部预制缺损、相应凸碰撞体、墙面轮廓；裂纹围绕同一个撞击中心铺到残壁。
