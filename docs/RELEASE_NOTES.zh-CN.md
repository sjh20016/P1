RAVAGE · Towerfall / Prototype 0.01

Godot 4.7.2 Stable 的 Windows x64 双触手摆荡与破坏原型。

- 固定 Blender 塔林，14 个可破坏部件。
- 独立双钩、弹簧拉力、松钩飞行、高速撞击与绷紧触手扫击。
- 每次 4–6 块真实碎片，48 个活跃刚体预算，自动回收。
- GPU 碎屑、短震屏与 Hit Stop、冲击音效、计分及 F3 调试。
- 自动三分钟物理测试与真正 Windows EXE 的扫击、渲染、回收测试通过。

下载 Windows ZIP，解压后双击 RAVAGE.exe。
Enter 开始，WASD 移动，按住左右鼠标抓取，松开飞行，Q/E 收放绳，Space 跳跃，R 复位，F5 重开。
F2 可直接进入带初始速度和右钩的扫击练习位置。

本版只验证核心玩法。后续计划按用户要求扩展到所有可见建筑都能破坏。
