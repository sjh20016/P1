# RAVAGE 0.04 · CONSEQUENCE

Godot 4.7.2 Stable / Windows x64 / Compatibility，中文界面。

- 三座重点测试塔：局部撞洞、内部穿越、切口残唇、支撑失效与倒塌。
- RAM 留下洞口、削角和放射黑痕；SLASH 留下长切口、错位结构与少量碎片。
- 大块先抖动、倾斜，再下坠；真实接触后塔产生 COLLAPSE 伤害，最后保留有碰撞的静态废墟。
- 伤痕随墙板和残骸移动。同局持续保留，上限 384；大块预算 6，碎片刚体预算 48，连锁深度最多 2。
- 保留 M03 移动基线、358 栋原塔林和 0.03 八站路线。随包内嵌 Noto Sans SC 中文字体。

解压 `RAVAGE-0.04-Windows.zip`，双击 `RAVAGE.exe`，Enter 进入实验场。

A 场景：空格起跳并抓正面塔身，撞入后松钩，保持惯性穿出，再抓出口梁。F9 切换切断、连锁和伤痕实验。R 回出发点并保留破坏；F5 重置；F4 原塔林；F6 后果实验；F10 原八站路线；F3 调试；F8 保存运行数据。

高级破坏只覆盖独立实验区域的三座塔，未铺满原塔林。切割采用预制切面，大块使用简化运动代理，废墟不跨程序保存。D06 双钩 Pull 未开放。自动验证和实际渲染证据随包提供；手感、倒塌节奏和残骸是否值得利用，仍请真人试玩判断。
