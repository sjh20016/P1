RAVAGE · Living Ink / Prototype 0.02

Godot 4.7.2 Stable / Windows x64。

- 全部 358 个建筑物件接入破坏，共 4,944 个预制段；出生平台、桥梁与抓取环同样可破坏。
- 击中处产生缺口，未毁部分保持抓取与碰撞。继续使用 48 个活跃刚体预算。
- 暖白塔林、黑色脉动核心、8 条视觉触须、渐细的双抓取触手与黑色断面。
- 抓取、快速擦墙及破坏留下会变干的墨迹。最多 768 处，每 32 处一批更新。
- 保留双钩弹簧摆荡、扫击、Hit Stop、粒子、声音、计分及调试 HUD。
- 修复曲面墨迹沉入模型、满额墨迹更新卡顿和带抓钩重开后残留墨迹的问题。

下载 Windows ZIP，解压后双击 RAVAGE.exe。
Enter 开始，WASD 移动，按住左右鼠标抓取，松开飞行，Q/E 收放绳，Space 跳跃，R 复位并保留破坏，F5 恢复地图和墨迹。
F2 进入可立即接管的扫击练习，F3 调试，F11 全屏。

建筑采用预制段替换，新增建筑碎片为代表性碎石；本版没有实时切网格、结构力学或整塔倒塌。
源工程、测试与离线资产工具保留在仓库；原版 0.01 发布包继续保留。
