八组常规回归测试全部通过。完整物理压力场景执行 21,600 次 physics_frame 等待（工程配置 120 Hz；含停顿与渲染等待的实际耗时更长），交替双钩、释放、复位，累计 240 次破坏。峰值速度 **51.685 m/s**，最大活跃碎片 **31**，最大墨迹 **239**，异常速度 / NaN 帧数 **0**，最终碎片全部回收。

压力场景在墨迹批次优化前完成；优化后重跑了八组常规回归、满额墨迹实机压力和导出 EXE 测试。没有重新运行物理模型未变化的整段长测。

## 图形与性能

最终主场景截图脚本中，扫击阶段瞬时采样 **51 FPS**，碎片消失后 **60 FPS**。

满额留痕测试在同一视野内保留 **768 处墨迹**，连续 480 个渲染帧中每 5 帧新增一处并覆盖旧记录：

| 指标 | 结果 |
|---|---|
| 最终 FPS 采样 | 60 |
| 帧间隔中位数 | 16.625 ms |
| 帧间隔第 95 百分位 | 18.081 ms |
| 墨迹绘制批次 | 24 |

最初使用整网格更新时，同场景第 95 百分位约 66.9 ms；改为只上传发生变化的 32 处墨迹批次后消除了这项主要卡顿来源。以上是固定脚本和本机集显的测量，不代表每个视角、全部建筑破损状态或其他设备的最低帧率。

实机核对菜单、玩家轮廓、锚环、触手、扫击、曲面湿墨 / 干墨与建筑缺口。曲面留痕从单扇面改为多圈采样，避免大墨点的内部沉入圆柱。默认关闭调试辅助色后，画面统一为黑白。

最终主场景、墨迹预算以及独立 Windows EXE 的错误日志均为空。导出 EXE 日志包含：

```text
EXPORT SMOKE fracture=true sweeps=2
EXPORT FULL WORLD break=true ink=true
EXPORT SMOKE RESULT PASS
```

## 重现

```powershell
./tools/run_checks.ps1 -Stress
./tools/build_windows.ps1
./build/RAVAGE-0.02-Windows/RAVAGE.exe -- --smoke-test
```

渲染脚本位于 `project/scripts/debug/capture_game.gd`、`capture_ink.gd` 和 `capture_ink_budget.gd`，以 Godot 的 `--script` 参数执行。开发测试、截图脚本与 GLB 导入中间资产排除在 Windows 游戏包之外。

`build/ink-final-checks.log`、`ink-checks.log`、`ink-budget.log`、`windows-0.02-smoke.log` 保存本机日志。`build/05-ink-clean.png` 至 `10-tower-cut.png` 是真实场景抓取、滑擦与局部破坏的对照截图；图中动作由脚本驱动。人工手感调参仍需后续试玩。

## 范围与近似

- 建筑是离线切分的固定段，约 24 米高；运行时替换预制场景，不切割新网格。
- 新增建筑的四块大碎石是代表性碎片，不逐体积还原被毁段。完整塔身不会因失去支撑自动倒塌。
- 扫掠判定对预制段包围盒做 SAT，保留 0.22 m 容差；边缘比逐三角形判定更宽松。
- 墨迹依附静态碰撞表面，预算满时覆盖最旧痕迹；没有跨次启动的存档。
- 玩家不接收碎片的刚体反推，以维持高速移动稳定。
