# RAVAGE 0.05 — IMPACT

本轮先修复动作反馈与伤害结算边界，0.06 再验证开放规模。

- 几何与得分立即结算；视听反馈使用 140 ms 节拍门限，结构高潮可提升优先级。
- SLASH 不触发全局慢速。近距离重撞最多 36 ms 慢速，650 ms 冷却；远距离后果不会同等震动镜头。
- 得分按真实破坏、结构断裂、连锁深度和连续换点计算，命中显示当次收益。无变化 PULL 不再刷分。
- 连续扫切按建筑表面与高度带冷却；新墙板已有局部伤痕，不重复投射旧墨迹。
- 音效分为空间撞击与裂响，倒塌采用更低音高；复用现有合成音源，未声称达到录音素材品质。
- 撞击增加短扩散冲击环、混凝土色碎屑，镜头振幅缩减并保留方向反冲。
