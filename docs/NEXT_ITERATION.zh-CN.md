# 后续目标：所有可见建筑都能破坏

用户于 2026-09-09 补充：后续调整最好全部都可以破坏。

Prototype 0.01 先交付有限地图和 14 处可破坏区域，验证摆荡、撞击和触手扫击。
下一阶段将静态塔身按高度提前分成可破坏段，逐步覆盖全部可见建筑。

- 在 Blender 中离线分段并准备完整 / 破碎配对，保存稳定的段 ID。
- 统一调用 DestructibleSegment.break_segment()；抓点随所属段失效。
- 一个段只产生 3–6 个大刚体，继续使用全场 48 个活跃刚体预算。
- 远处破坏优先用静态破损替换与 GPU 碎屑，避免整塔刚体。
- 保持有限固定地图，不引入实时切网格、结构力学或无限地图。
- 先完成可破坏覆盖，再用实际 profiling 决定是否需要对象池。
