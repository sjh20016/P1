# 0.06 试玩指南

双击 `开始游戏.cmd`，或分发目录的 `RAVAGE.exe`。Enter 进入开放塔林，准备约半秒后开放控制。

## 第一轮：穿塔

起点正面是能量塔。空格起跳，按住左键抓塔；撞穿以后松钩保持惯性，从另一侧穿出，再抓下一座塔。
首次身体撞开能量塔得到一次加速。普通墙需法向速度 26+；标记重壳需 38+。擦过墙面不等同于正面撞击。

## 第二轮：选目标

自由契约：破坏 8 栋建筑、切断 2 处弱缝、造成 2 次连锁。没有指定顺序；用弱缝塔和邻塔的位置规划路线。
弱缝由塔身低处黑线及“弱缝 / 切断连锁”标志提示。抓高处目标绕侧面摆荡，让触手绷紧、高速扫过低处接缝。仅挂钩不产生切割。
切断后前方落块会遮挡或改变通路，提前选择松钩与逃离方向。完成契约后世界继续运行。

## 第三轮：回访

从一端飞到另一端，破坏多栋，再返回第一处洞口。它仍应可穿过；原黑痕可能因为同塔较新伤口覆盖而变少，但主洞口不得恢复。
抓住未受损墙面，擦切附近墙面，抓点应保持。真正破坏抓点后触手应释放。

## 操作

WASD 移动/空中微调；空格起跳；鼠标左/右键抓取；Q/E 收放绳。
R 回起点并保留本局破坏；F5 重开当前区域及契约；F4 开放区；F6 原后果实验，F9 切换实验；F12 原塔林；F10 原移动路线；F3 调试；F8 保存遥测；Esc 暂停；F11 全屏。

## 请重点判断

1. 撞击后能否立刻知道打开了通道，连续切割是否仍有抽搐感。
2. 重壳、能量和弱缝是否改变了你的路线选择。
3. 是否在高速运动中注意到连锁，而不是停下来寻找结果。
4. 破坏几十栋以后是否出现持续卡顿，回访是否发生墙面恢复或抓钩失效。

自动脚本能验证接触、状态和帧时间，不能证明手感“爽”。
