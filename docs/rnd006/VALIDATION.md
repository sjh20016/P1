# 0.05 → 0.06 验证记录

## 判据

本轮主要验证四件事：真实穿越与抓点连续性、破坏后回访不恢复、宏块接触产生真实二次伤害、持续开放破坏的成本有界。分数与反馈只在实际损伤后产生。

自动飞行按路线移动测试角色，通过同一伤害入口命中墙面，保留渲染、碎片、特效与宏块碰撞。它是重复负载，不等同于真人操作；真实角色扫掠穿墙另由功能测试覆盖。

## 功能覆盖

`tools/run_checks.ps1 -Rnd -Consequence -Stress -Open` 覆盖 21 个测试脚本：

- 原移动、抓取、破坏、扫切、特效、生命周期、358 塔世界与旧墨迹。
- 四项移动研发验证、六项后果系统验证、三分钟综合负载。
- 0.05 的视听节拍与结算边界。
- 0.06 的独立状态、紧凑墙体、真实穿越、稳定抓点、远近切换、实际邻塔接触、废墟回访和重置。

本轮曾发现地基附近的宏块接触抖动导致永不稳定。修复采用持续接触与空间位移窗口；没有加入超时空中冻结。修正后的独立开放区测试通过，随后重跑完整回归。

最终 21 个测试脚本全部通过，结果包含修正后的定向复测，汇总见 [final-checks.log](evidence/final-checks.log)。综合负载峰值 32 个刚体、236 个旧墨迹，未发生非有限位置或超速；开放区新增验证也覆盖真实瞄准抓墙、能量消耗和破坏抓点后释放。

## 图形与持续运行

测试设备：Intel UHD Graphics 730，OpenGL 3.3 Compatibility，驱动 32.0.101.7088，Godot 4.7.2，窗口 1280 × 800。帧时间使用真实时钟；物理采样值不代表 GPU 时间，Godot 静态内存也不等于整进程或显存占用。

第一次修正后的五分钟原生音频运行：224 次访问、188 次回访、36 栋实际受损、三次结构连锁、三个稳定废墟，回访状态错误为 0。该次运行发生音频设备失效错误和秒级停顿，不能作为“稳定 60 FPS”的通过证据。

更早的图形启动曾在旧塔林资源预加载阶段发生内存分配失败。开放区已改为不预加载旧 358 塔；旧塔林仅在用户进入时加载。这个修改消除了随后开放区短测与五分钟运行的启动崩溃，但没有声称改善旧塔林自身的展开成本。

原始日志与采样见 [evidence](evidence/)，最终指标见 [性能记录](PERFORMANCE.md)。
