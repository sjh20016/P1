# 0.07 集中试玩

解压后运行 RAVAGE.exe；工作目录也可双击根目录“开始游戏.cmd”。Enter 进入开放塔林。

## 一次连续游玩即可

先按以前的方式撞开正面能量塔、扫切弱缝，在塔林里自由穿行。看到黑环牵引核时试一次双拉，继续去别处破坏，之后回来看看废墟。无需分开跑实验场。

**双拉操作：**

1. 起点右侧是第一对黑环双塔。移动到它们之间，稍靠前一些，更容易同时看清内侧墙面。
2. 左键抓住其中一座黑环附近的完整墙面，保持左键；转头用右键抓住另一座。
3. 保持两键并按住 Q。张力不足时继续收绳；站位、目标或名额不满足时看上方提示。
4. 黑裂长满后自动扯断并松钩。保持移动或抓其他墙飞离交汇处，观察大块是否撞在一起、结果是否容易看懂。

黑环是识别标记，不必精确命中环中心；实际抓点须位于弱缝上方的完整墙面。移动大块不能抓取，落稳的废墟可以。

自由契约：八栋不同建筑，加“两条弱缝与两个连锁目标”或“一次双塔互撞”。完成后可继续玩。地图另有一对牵引核。

## 操作备忘

WASD 移动，空格起跳；Q/E 收放绳；鼠标左/右键控制两条触手。R 回起点但保留本局破坏；F5 清空重开；Esc 暂停；F3 调试信息；F8 保存本局数据。

## 玩完最有价值的反馈

- 能否顺利做出双拉，提示是否让你知道哪里没满足条件？
- 拉断、互撞、碎裂和得分是否形成一个清晰、够重的瞬间？
- 自由选目标是否开始有意思，连续破坏和回访时是否出现卡顿或大块异常？

出现问题时可按 F8 留下本局数据，描述当时动作即可。本版尚未跑自动玩法回归，不需要把问题当成自己的操作失误。
