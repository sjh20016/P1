# 0.07 · 双塔牵引与互撞

## 这一轮解决什么

在已获真人初步认可的 0.06 开放塔林上，增加一个需要选位置、选目标、建立张力并及时离开的动作：双钩扯断两座牵引核，让大块迎面碰撞。保持原有移动和 36 塔规模。

## 已接入的内容

- 两对牵引核：靠起点右侧一对，塔林较深处另一对。黑环标记抓取位置，下方黑线标记断裂高度。
- 双钩必须抓住不同的有效牵引核，玩家位于两塔之间，按住 Q 建立两侧张力。蓄力有进度条、向上黑裂和两段拉扯声；松开 Q 会衰减，松钩、暂停、重置会清除。
- 蓄满一次切断两个弱连接，生成朝彼此运动的大块，并自动释放抓钩。大块实际平移碰撞后，接触部位产生缺口、碎片、黑痕、扩张冲击环和空间音效。
- 互撞奖励只给实际造成破坏的首次接触。同一对大块不能靠持续贴合重复拿分。普通连锁按不同建筑计数。
- 自由契约要求破坏八栋建筑，再选择两处弱缝加两个连锁目标，或一次双塔互撞。完成额外 +1500，不抢占刚发生的互撞提示。
- 瞄准提示区分普通墙、重壳、能量、弱缝和牵引核；抓点或站位不合适时显示原因。

## 仍然采用有限模拟

保留最多三个活动宏块、48 个真实碎块、两层连锁。双拉先检查两个空位；普通结构破坏沿用排队。旋转按程序控制，平移通过实际碰撞查询，落稳后压成持久静态废墟。没有引入完整绳索物理或通用结构求解器。
