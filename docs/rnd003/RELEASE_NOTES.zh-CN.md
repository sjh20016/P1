# RAVAGE 0.03 · MOMENTUM / IMPACT

Godot 4.7.2 Stable / Windows x64。

- 默认 Hybrid 抓钩：命中瞬间拉出、持续主动发力、绳长约束；保留 1 / 2 / 3 三种算法切换。
- 窄锥可见表面辅助、候选标记与 Miss 原因；危险坠落扩大有限辅助范围。
- 点按 ZIP、按住摆荡、Q 收绳蓄力、释放弹出；双手共享瞬间加速冷却。
- 身体撞穿产生分结构的法向速度损失、方向反冲和裂解声；绷紧触手扫切更轻快。
- 坠落宽限、紧急救援、可选 Shift 贴墙 + Space 蹬出。
- 固定八站路线，验证撞穿捷径、切梁后新抓取角度和内部空间；一个檐板支持轻量下落反应。
- 继承可破坏塔林与 Living Ink 美术，维持 48 刚体、768 墨迹预算；改善大量分段下的扫切卡顿。
- F8 保存一局数据，附带四份研发报告。真人手感和完整路线用时仍需后续试玩。

解压后双击 RAVAGE.exe，Enter 开始。WASD 移动、鼠标左右抓取、Q/E 收放绳、Space 跳跃、R 回检查点、F5 重开、F4 自由塔林、F6 课程、F2 切割练习、F3 调试、F11 全屏。

建筑使用预制段替换，新增碎石为代表性碎片；没有实时网格切割、普遍整塔倒塌或结构力学。全部建筑进入分段状态时，本机集显约 30–38 FPS。完整源码、离线工具与测试保留；0.01 / 0.02 本地构建继续保留。
