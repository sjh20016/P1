# RAVAGE 0.03 · MOMENTUM / IMPACT

2026-09-10，Godot 4.7.2 Stable，Windows x64。基于本地 0.02 的 358 个建筑、4,944 个预制段与 Living Ink 美术继续研发。

- 默认抓钩改为 M03：命中速度脉冲、持续肌肉拉力、弹簧与径向约束共同工作。M01 原弹簧、M02 摆锤约束保留为数字键 1 / 2 的比较组，3 返回默认。
- 中心射线未命中时，搜索窄锥内可见表面；验证从玩家到命中点的遮挡、距离和前方方向。危险坠落时有限扩大辅助角度。显示候选点、距离与失败原因。
- 同一根触手支持点按 ZIP、按住摆荡、Q 收绳蓄力、释放弹射。双手共享脉冲和释放加速冷却；自动脱钩不触发蓄力加速。
- 身体撞穿门槛为法向入射速度至少 26 m/s；轻、中、重结构分别保留法向速度 90%、82%、68%，切向保留 99%。成功破坏后继续移动。
- 触手切割需玩家速度至少 20 m/s、张力至少 12，且绳段确实扫动。切割不直接削减玩家速度；停顿、震屏、尘量弱于身体撞击。
- 加入抓取发射、附着、张力、松钩声音，及撞击裂解、切断声层；相机方向反冲、FOV 脉冲、身体挤压和定向碎片组成反馈。墨迹沿动作方向拉开，预算仍为 768。
- 旧版约 -100 m 的重置线改为坠落宽限；附近存在可救援表面时保留操作。仍在上升或抓住有效目标时不因一次空搜索重置。硬下限 -800 m；无抓点、停止上升并持续危险状态后快速回到检查点。
- 增加固定八站实验路线：抓取、撞墙捷径、交替钩、切梁、内部空间、坠落救援、可选贴墙蹬出、重型终点。Enter 默认进入，F4 自由塔林，F6 重开路线。
- 贴墙实验仅在 F7 开启或到达对应站时生效：低速接触墙面按 Shift 短暂停留，最长 0.45 秒；Space 向外上方蹬出。
- 切掉指定横梁可让一块檐板倾斜、延迟落下并回收；该反应最多一个视觉代理。保持静态建筑与有预算碎片的架构。
- F8 导出完整一局遥测；正常完成路线自动保存。F3 + F10 可调试跳站，记录为 assisted，完成提示与正常通关区分。
- 对切割加入物理空间筛选，再做原有 swept-quad SAT。大量建筑保留分段状态时减少全量扫描；候选达到上限时回退完整集合，避免截断漏检。
- 修复新模块的循环类型引用导致的资源残留，以及实验路线重开后的操作状态；保留原资产和 0.01 / 0.02 构建。

本轮没有添加新攻击类型、实时网格切割、真实结构力学或流体。建筑仍按离线分段产生缺口；悬空塔段不会普遍自动倒塌。
