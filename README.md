**当前 Portal 原型：** 双击 `开始传送门原型.cmd`，默认进入 `资产模型/VerticalCanyon.blend` 导入的垂直峡谷。132 个塔体均支持局部破坏；空格锁定后可用鼠标旋转切割面，切割双门持久保留、可穿越并可按住 V 移动；Shift 蓄速有循环下坠表现。操作与验证见 [PORTAL-CANYON.md](PORTAL-CANYON.md)。下文仍为原触手游戏历史说明。

Godot 4.7.2 Stable / Windows x64 / Compatibility。黑色生物在白色塔林中高速抓取、撞穿墙面、切断弱缝；本版加入双塔牵引和大块互撞。

## 直接游玩

双击 **开始游戏.cmd**，或 **build/RAVAGE-0.07-Windows/RAVAGE.exe**。分发包解压后直接启动 RAVAGE.exe，不需要安装引擎。
Enter 进入 36 栋塔的开放区域。空格起跳，按住左键抓住正面的能量塔；撞开后松钩穿出，再抓下一个目标。

右侧有一对带黑环的牵引核。移动到两塔之间，用左右鼠标键分别抓住两座塔的黑环附近完整墙面，保持双钩并按住 Q。两侧张力足够后黑裂向上蔓延，蓄满自动扯断并松钩。保持移动，离开大块交汇处。地图内共有两对牵引核。

自由契约：破坏 **8 栋不同建筑**，再任选 **切断 2 处弱缝并波及 2 个连锁目标**，或 **完成 1 次双塔互撞**。顺序自由；完成额外获得 1500 分，之后可以继续探索。

| 操作 | 按键 |
|---|---|
| 移动 / 空中微调 | WASD |
| 左右触手 | 按住鼠标左 / 右键，松开保持惯性 |
| 收绳蓄力 / 放绳 | Q / E |
| 双塔牵引 | 双钩分别抓住牵引核，站在两塔之间并按住 Q |
| 起跳 / 回起点并保留破坏 | 空格 / R |
| 重置当前区域和契约 | F5 |
| 开放区 / 原后果实验 | F4 / F6 |
| 下一后果实验 / 旧塔林 | F9 / F12 |
| 原八站移动路线 | F10 |
| 调试 / 保存遥测 | F3 / F8 |
| 暂停 / 全屏 | Esc / F11 |

普通身体撞击需法向速度 26+ m/s，标记重壳需 38+。扫切需速度 20+、足够张力和实际绳段扫动。仅挂钩不会切断塔；双塔牵引只对标记牵引核生效。瞄准建筑可看到对应提示。

## 迭代内容

**0.05 IMPACT**：几何结算与视听节拍分开；连续扫切不反复全局慢速；按真实结果显示收益；减少重复伤痕投射；改进方向反馈、空间音效和碎屑。

**0.06 OPEN DESTRUCTION**：96 个逻辑墙格以合并矩形绘制和碰撞，不为每格创建节点；附近保持精确缺口碰撞，远处释放碰撞代理并保留损伤数据；稳定抓点身份跨重建保留。三座弱缝塔可落块连锁；普通、重壳、能量和结构目标提供路线选择。

**0.07 DUAL PULL**：双钩选塔、张力蓄力、黑裂与拉扯音、断裂后自动松钩接入同一个动作流程。大块向彼此倾倒，实际平移接触触发破坏与一次性互撞奖励；受撞外壳更新缺口，落稳成为可回访废墟。移动大块会遮挡抓钩视线。契约提供连锁与牵引两条路线。

0.05、0.06 独立分发包仍保留在 build/；0.07 包为 build/RAVAGE-0.07-Windows.zip。

## 验证与边界

[本版说明](docs/rnd007/RELEASE.md) · [集中试玩指南](docs/rnd007/PLAYTEST.md) · [架构与验证边界](docs/rnd007/ARCHITECTURE.md)

按本轮要求集中开发，**0.07 未运行分项玩法回归、自动试玩或新一轮性能测试**，交由真人集中试玩。导入与导出检查仅确认构建完整性。互撞成功率、操作手感、落稳表现与持续性能仍待本版试玩确认。

保留 36 塔、三个活动宏块、48 个真实小碎块、连锁深度 2 的预算。双拉需要同时空出两个宏块名额；预算不足时会提示等待。

本局保存洞口、切口与废墟，不保存到下一次启动；同一塔最多保留八次主要伤痕。普通塔没有结构图，只有标记弱缝塔整体倒塌。地面、地基与起点平台不可破坏。
当前切割和倒塌使用近似，宏块采用程序倾转与实际平移碰撞，没有精确旋转扫掠；移动宏块不可抓取。没有全城任意切割或物理绳索链。音源仍为合成占位素材，音色和爽感需真人判断。
F12 的原 358 栋塔林保留旧分段系统，未把新系统直接推广到所有旧资产。
